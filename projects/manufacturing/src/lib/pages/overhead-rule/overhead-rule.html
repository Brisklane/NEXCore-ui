How Rules Are Used Rules with an LR- code prefix are labor rates (managed on the Labor Rates page). All other active rules are overhead allocations applied during Standard Cost calculation. Percentage rules multiply against the running cost base. PerHour rules multiply against total routing hours. Fixed rules add a flat amount.
